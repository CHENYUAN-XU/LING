# 数据与隐私边界

Project Mnemosyne 当前是本机优先项目。账号、人格、聊天、记忆、授权状态、上传文件和运行日志默认保存在主项目目录内。

## 保存什么

- 账号与资料：账号名、昵称、头像、生日、性别、签名和简介。密码只保存哈希。
- 聊天与人格：人格资料、会话、消息、未读状态、表达标签、群聊和人格成长记录。
- 记忆与画像：摘要、事实、关系、偏好、冲突审计和召回痕迹。
- 授权状态：Voice、Live2D、Camera、Screen、Proactive 和 Video Companion 的用户授权。
- 运行日志：request id、路径、状态码、耗时、客户端标识和 5xx 异常类型；不记录请求正文。

## 用户控制

- `GET /api/account/export` 和 `py scripts\export_user_data.py --user-id ...` 可导出用户 JSON 数据，排除 password hash 和 session token。
- `py scripts\backup_data.py` 可生成数据库一致性快照，并把上传文件和 manifest 打入本地 zip。
- 资料弹窗提供账号彻底删除入口；正式账号需要账号名和当前密码，游客账号需要账号名。
- 已删除人格先进入可恢复状态；永久删除需要在“已删除”面板再次输入人格名确认。
- 游客账号默认 3 天后清除账号、人格、聊天、记忆和上传目录。

## 设备与外部项目

真实设备能力默认关闭。Camera、Screen、Proactive、Video Companion 等入口需要配置启用并由用户显式授权。

实时摄像头视频陪伴已经独立到外部项目 `E:\视觉\video-companion`。主项目不继续承担连续摄像头帧理解、实时语音状态机、视觉模型 token 调度或视频会话 UI；主项目只保留授权边界、人格上下文、状态入口和明确授权后的摘要回写接口。后续转到其他聊天时，也应跳过重做这个外部项目，只做主项目接入和验收。
